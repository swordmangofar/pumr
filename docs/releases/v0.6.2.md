# pumr v0.6.2

A Linux release for X11 desktops such as Pop!_OS: pasted images arrive as
attachments again, the interface no longer grows blurry and oversized with the
desktop's text scaling, and the window-toggle shortcut brings pumr to the front.

## 🐛 Bug Fixes

- Fixed images pasted into the composer on Linux landing in the text box as a full-size picture that was never sent. WebKitGTK hands a copied image to the page only through its own paste; pumr now moves it into the attachments as a PNG.
- Fixed the interface looking blurry and oversized on Linux when the desktop's text scaling is above 100% (a common way to get fractional scaling on X11). WebKitGTK 2.46 and later zoom the whole page by the font DPI, which squeezed the layout and rendered it at a fractional scale; pumr now undoes the fractional part and follows changes to the setting while it runs. Whole scales such as `Xft.dpi: 192` are kept, and pumr's own zoom (Ctrl +) sizes the interface.
- Fixed the window-toggle shortcut on X11 not bringing pumr to the front: GNOME's focus-stealing prevention rejected the request because it carried pumr's last input time. pumr now asks for focus with the current X server time.
- Fixed the window-toggle shortcut on X11 never hiding or minimizing pumr: the shortcut's key grab takes keyboard focus while the key is down, so pumr always looked unfocused. pumr now asks the window manager which window is active.

## 🔧 Maintenance

- The interface zoom is applied by the backend (`set_interface_zoom`) so platform corrections live in one place; the webview zoom permission is no longer needed.
- Added an e2e test that replays WebKitGTK's image paste, and Rust tests for the font DPI correction.
