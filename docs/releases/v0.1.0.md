# pumr v0.1.0

The first public release. pumr is a local-first, provider-agnostic agentic coding
harness for the desktop, built with Angular 22 and Tauri v2, powered by OpenRouter.

## 🚀 Features

- Multi-tab agent sessions grouped by project, with persistent history in SQLite and archive/delete.
- Streaming responses with collapsible reasoning and a live agent status indicator.
- Sub-agents via the `task` tool, each appearing as its own session with its own shadow-git base commit.
- An `ask`/`question` tool with an in-app overlay so the agent can ask you for decisions mid-run.
- `@` mentions in the composer: files, directories, websites, skills and MCP tools resolved into structured context.
- Model Context Protocol (MCP) client supporting stdio and streamable-HTTP servers, discoverable per message.
- Workspace mode with a file tree, Monaco editor and single/split diff views.
- Composer attachments for images, PDFs and text files, with multipart message content.
- Inline and side-by-side diffs for changed files, with `+additions`/`-deletions` counts.
- Local spend statistics with day and hour breakdowns.
- Custom themes and editable hotkeys.
- Agent rules settings with global, project and nested `AGENTS.md` files merged into the system prompt.
- 24 UI languages with runtime language switching.

## 🔧 Maintenance

- Initialised the project, Angular values and the Tauri v2 shell.

## 🔒 Security

- Tool calls are sandboxed to the active project and explicitly allowed extra folders.
- Every non read-only command requires approval by default.
- Secrets are kept in the OS keychain rather than on disk.
