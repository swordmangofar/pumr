# pumr v0.3.0

The biggest release so far. pumr gains a full Git client, file access rules, a
session debugger, a reorganised settings dialog and in-app auto-updates.

## 🚀 Features

- Added a complete Git integration: status, branches, log and commit details, per-file diffs, staging and unstaging, discard, commit, checkout, fetch, pull, push, remotes, fast-forward, merge, rebase (including interactive rebase), branch create/rename/delete, tags, set-upstream, push-branch and open pull request.
- Added a commit graph renderer with branch lanes.
- Added a `projects | workspace | git` tab set to the left sidebar, with the active tab persisted.
- Added file access rules: ignore gitignored files, generated files, local databases and environment files, each with exemptions and an advanced mode.
- Added a built-in ignore catalog covering generated folders and files, databases, environment files and credentials.
- Added a session debugger showing a live timeline of the context and system prompt, mode configuration, messages, tool calls, sub-agents, questions, MCP and skill calls, with filters and token/cost summaries.
- Added in-app auto-updates with idle, checking, available, downloading, ready and error states plus download progress.
- Added an Updates section to settings.
- Added a More tabs dropdown that collapses overflowing tabs on smaller windows.
- Added project appearance options directly in the settings flow.

## ✨ Improvements

- Split the settings dialog into dedicated Chat, Appearance and Notifications categories.
- Reworked the appearance settings to cover theme, custom theme, background, blur, opacity, glass opacity and high contrast.
- Reworked the notifications settings with built-in and custom sounds, volume and preview.
- Persisted layout choices such as the left and right tabs and the active session view.
- Persisted composer drafts and attachments per session.
- Refined the workspace and general UI polish.

## 🐛 Bug Fixes

- Fixed the updater release inputs and switched CI to the local Tauri CLI.
- Fixed tabs overflowing at smaller resolutions.

## 🔧 Maintenance

- Rewrote the installer workflow around `tauri-action` with signing secrets and updater JSON.
- Moved to OS and architecture aware release asset names (`pumr-[version]-{windows|mac|linux}-{amd64|silicone|intel}`).
- Ad-hoc signed macOS bundles and renamed the macOS assets to silicone and intel for clarity.
- Added the `git` and `debug` i18n namespaces across all 24 locales.

## 🔒 Security

- Enforced the file ignore rules on reads and globs, refusing to touch ignored or sensitive files.
- Skipped `.git` internals from tool access.
- Made exemptions explicit so they can override every rule.
