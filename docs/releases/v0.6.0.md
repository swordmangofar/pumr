# pumr v0.6.0

A big feature release: an integrated terminal, line-level staging and a full
commit/branch toolbox in the Git view, a reworked permission system with presets
and a decision log, one-click MCP server installs and a remappable hotkey
system.

## 🚀 Features

- Added an integrated terminal dock below the chat or editor, with multiple tabs, copy/paste/clear shortcuts and a toggle hotkey.
- Added line-level staging in the Git view: select lines or hunks by click, drag or shift-click, then stage, unstage, discard, copy or "Ask pumr" about them. The new diff view supports side-by-side mode, context lines or whole file, hidden whitespace, line wrapping and find (`Ctrl`/`Cmd`+`F`).
- Added a commit context menu: check out, new branch or tag here, cherry-pick, revert, reset (soft, mixed, hard) and copy SHA or message.
- Added interactive rebase (pick, squash, fixup, drop, reorder), force-delete for unmerged branches and in-progress merge, rebase, cherry-pick and revert handling.
- Added conflict resolution per file: use ours, use theirs, or edit and mark as resolved, with a warning when conflict markers remain.
- Added multi-select for files in the Git view to stage, unstage or discard several at once.
- Added AI-written commit messages, with a configurable commit message model.
- Added permission presets (Strict, Balanced, Autonomous, Custom) with fine-grained automatic approval for read-only commands, package managers and build runners, project executables and all in-project commands.
- Permission prompts now show the agent's one-sentence reason ("Why") and numbered choices: yes, yes for this chat, yes until restart, always allow, no, always deny. Scopes can be customized to a folder and its subfolders or a website and its subdomains, and one grant approves every queued request it covers.
- Added a Permissions view in the debugger that records every permission decision in a chat and why it was made.
- Added one-click MCP server installation from the registry: review the command and required credentials, then add it to pumr's own MCP config. Installed servers are always available, even with auto-detection off.
- Added Installed tabs and update/reinstall actions for MCP servers and plugin marketplaces.
- Added a capability picker for modes with filtering, selection counts and a warning for skills or servers that are no longer available.
- Added a reworked hotkeys panel grouped by category, covering sessions, chat, Git, diff, editor, permission prompts and panel focus navigation, with fixed shortcuts listed for reference.
- Added separate subagent and compaction model settings.
- Added prompt caching for providers that support it, with cache read and write tokens tracked in usage.
- Added progressive MCP tool disclosure: with many MCP tools connected, a `tool_search`/`mcp_invoke` pair replaces inlining every schema to save context.
- Added a retry button for failed turns, a context usage breakdown (system, history, tools, tool output) and a handover suggestion when the context is almost full.
- Added "Recommended" markers in agent questions.

## ✨ Improvements

- Chat markdown is now rendered with `marked`, with dedicated code, block and inline components.
- Consecutive read-only tool calls (`read`, `glob`, `grep`, `ls`, `webfetch`, `websearch`) run concurrently in bounded batches, while writes, edits and `bash` keep their place in the order.
- The latest user prompt is pinned during history trimming and compaction, so long tool loops no longer push it out of view.
- OpenRouter requests are retried with exponential backoff and honour `Retry-After`; a stream that already delivered content is never replayed.
- The spend indicator now uses the credit limits reported by OpenRouter for your API key instead of a manually entered budget.
- A webview reload during a turn now re-attaches to the running turn, restoring the Stop button and any pending permission prompts or questions.
- Network commands such as `curl`, `git` and `ssh` follow the same website allow/deny list as the web tools.
- Read-only inline code (`node -e`, `python -c`) and `npx` for tools the project already installed can be auto-approved under the matching presets.
- Tool groups show file and command counts, and composer hints reflect your configured shortcuts.
- Binary and oversized files show a notice instead of a broken preview.

## 🐛 Bug Fixes

- Fixed projects located below a folder with a generated-looking name (`/tmp`, `build`, `dist`, `vendor`, …) being hidden entirely from `glob`, `grep`, `ls` and `read`.
- Fixed silent notification sounds in the Linux AppImage by bundling the GStreamer plugins WebKitGTK needs, with a private GStreamer registry so the user's shared cache is left alone.
- Fixed Stop being unable to reach a turn after a replaced turn exited late, and an early error leaving a turn listed as running.

## 🔒 Security

- Rewrote command analysis on top of a dedicated shell lexer, so inline code (`bash -c`, `node -e`), package downloads (`npx`) and hosts contacted by network commands are detected and always ask unless explicitly allowed.
- Autonomous mode shows an explicit warning and confirmation before trusting a project's scripts and executables.
- Permission prompts warn when a URL carries a lot of data in its query string.
- Website rules that do not cover the requested host, or are too broad, are narrowed to the requested host.
- The agent's permission reason is treated as untrusted display text, capped at 300 characters, and never affects the decision.
- Environment values of installed MCP servers are stored in a config file readable only by your user account and are hidden from server summaries.

## 🔧 Maintenance

- Added a `pnpm verify` script and a Verify workflow that builds, tests and checks the backend on every push and pull request.
- Added an AppImage verification script to CI that checks the bundled GStreamer plugins load.
- Changed the dev server port to `2500`.
- Added `portable-pty` for the terminal backend.
- Added specs for the hunk diff view, diff rows, markdown rendering, Git name dialog, question overlay, tool groups, capability catalog, composer, stick-to-bottom and re-attaching running turns.
