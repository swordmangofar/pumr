# pumr v0.6.1

pumr is no longer tied to OpenRouter: connect Anthropic, OpenAI, Google, xAI,
Mistral, DeepSeek or Groq directly with your own key, turn on a local model
server like Ollama or LM Studio, or pick from 190+ more providers loaded from
the models.dev catalog. A rebuilt model picker groups everything by provider.

## 🚀 Features

- Added direct model providers: Anthropic (native Messages API), OpenAI, Google, xAI, Mistral, DeepSeek and Groq, each with its own API key, request format and pricing. Every model id names its provider (`openai:gpt-5`), so a saved model alone decides where a request goes.
- Added local model servers (Ollama, LM Studio) that need no API key: start the server, turn the provider on, and its models appear in the picker.
- Added the provider catalog from models.dev (the open catalog opencode uses): 190+ providers with their API endpoints, models, prices and capabilities, cached on disk and refreshed daily. Providers that need cloud credentials or a sign-in are not included.
- Rebuilt the Providers settings: search and browse all providers with popular ones first, add an API key ("Get a key" links to the right page), override the API base URL, toggle which providers show models in the picker, and refresh a provider's model list with per-provider error reporting.
- Rebuilt the model picker as a shared model menu grouped by provider, with provider marks and names, "Served by {{ provider }}" hints, and an All/Favorites filter. The composer always shows which provider serves the selected model.
- Added prompt caching for direct providers that support it; Anthropic requests also cache the conversation so far. Assistant turns store the provider's own content so they can be replayed to that provider verbatim.

## ✨ Improvements

- A model list load already running is shared instead of duplicated, and a refresh asked for meanwhile runs once more afterwards, so saving a key or enabling a provider always shows up to date.
- One provider failing to list its models no longer hides the models of the others; its error is shown on the provider instead.
- The "no key" empty state now points to connecting any model provider, not only OpenRouter.

## 🐛 Bug Fixes

- Fixed the file sandbox following symlinks only when their target already existed; a symlink is now followed to where it really leads, so writes through links can no longer escape the project.
- A failed revert now reports the error on the session instead of throwing, and reverting is refused while a turn is still writing what a revert would take back.

## 🔧 Maintenance

- Added `pnpm docs:screenshots`, a Playwright run against the e2e fake backend that captures the README screenshots (hero and per-feature scenes), and `pnpm docs:banners`, which draws the abstract feature banners for the README.
- Reworked the README with real screenshots and feature banners for every section, now covering system prompts and modes as well.
- Provider settings, key storage and key flags have dedicated Rust tests; the e2e suite covers connecting a provider with its key, enabling a local server, searching the provider catalog and picking a model from the model menu.
- Assistant turns can store the provider's exact response (`provider_content`) for faithful replay.
