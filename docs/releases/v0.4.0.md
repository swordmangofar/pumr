# pumr v0.4.0

Rounding out Git, opening up the plugin ecosystem and giving the agent loop more
control: MCP and Skill marketplaces, per-session message queues, session handover
and a configurable tool-call limit.

## 🚀 Features

- Added an MCP marketplace browsing the official registry and the Build with Claude directory, with search, one-click install and a verified-only filter on by default.
- Added Skill marketplaces that read Claude-style `marketplace.json` manifests, letting you add, browse, install and uninstall skills.
- Added curated recommendations for quick installs.
- Added a Verified/Trusted model that pins curated marketplaces to a commit SHA and blocks reserved names.
- Completed the Git client with pull strategies (fast-forward only, merge, rebase), abort and continue for in-progress operations, stash push/apply/pop/drop, tags with push and delete, submodule update, repository init and clone.
- Added a conflict banner with detection of the operation in progress.
- Added a per-session message queue with a queue button, a queued-count chip and per-item remove and clear.
- Added session handover, which summarises an existing session into a new one.
- Added PDF attachments to the composer, plus line counts on text attachments.
- Added a configurable maximum tool iterations setting (default 35) with a paused banner offering Continue, Auto-continue session and an always toggle.
- Added `auto_continue_all_sessions` to let every session continue automatically.
- Added allow/deny lists for websites in permissions.
- Added folder grants that last until restart and are never persisted to settings.

## ✨ Improvements

- Reworked the permission model: dangerous commands inside the project are now allowed, and pumr only asks for sensitive files such as `.env`, keys and databases.
- Added a dangerous-program list (`rm`, `rmdir`, `unlink`, `shred`, `chmod`, `chown`, `chgrp`, `mv`, `truncate`) that auto-allows when every path token stays inside the project.
- Unified sensitive-file detection between the command gate and the file gate so the two can no longer drift apart.
- Grouped settings into prompt, mode, model, permissions, integration, appearance and interface sections.
- Reworked mentions so skills resolve as their own kind and installed skills are passed through.
- Extracted the composer editor into its own service and refactored the composer.
- Expanded the README into a feature overview with dedicated illustrations.

## 🐛 Bug Fixes

- Fixed the Git file operations that failed on paths with unusual names.
- Fixed marketplace search and install edge cases.
- Fixed attachments not being preserved when resending a queued message.

## 🔧 Maintenance

- Added `docs/PLUGINS.md` documenting the marketplace trust boundary.
- Added `AGENTS.md` with project conventions.
- Added a development-only Tauri config with DEV-badged icons.
- Added icon tooling for development builds.
- Added i18n keys for the new features across all 24 locales.

## 🔒 Security

- Documented and enforced the marketplace trust boundary: metadata only, no auto-execution, verbatim file copies and installs confined to the app data directory.
- Defaulted marketplace browsing to verified entries only and blocked reserved marketplace names.
- Removed the git-tracked heuristic from dangerous command evaluation in favour of explicit path checks.
