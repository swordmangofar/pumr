# pumr v0.5.0

A polish-and-hardening release: window summoning, image annotation, PDF previews,
richer agent tooling and a much stricter permission and CSP story.

## 🚀 Features

- Added a window settings panel with a global summon shortcut (register, suspend, toggle), hide and minimize behaviour, cross-monitor centering and a persisted display zoom.
- Added `Ctrl`/`Cmd` `+`, `-` and `0` zoom hotkeys backed by a dedicated zoom service.
- Added an image annotator with arrow, rectangle, ellipse, draw, highlight, crop and text tools.
- Added a lazy-loaded PDF preview for attachments, rendered with `pdfjs-dist`.
- Added per-file commit history that follows renames, plus `git blame`.
- Added a Git file context menu with stage, unstage, discard, blame, history, ignore, open and reveal.
- Added an agent graph view for the debug timeline with branch rendering and sub-agent prompt display.
- Added a configurable primary allow action for permission prompts (once, session or always) with keyboard shortcuts.
- Added sidebar hotkeys for creating and deleting sessions.
- Persisted composer drafts and attachments per session.

## ✨ Improvements

- Trim agent history to the model's context window so long sessions stay within limits.
- Kept tool outputs valid when a turn is cancelled.
- Made provider requests cancellation-aware so cancelling stops in-flight OpenRouter calls promptly.
- Poll for update availability instead of checking only once.
- Rounded out settings, loader and styling polish across the app.
- Expanded the README with per-feature illustrations and a screenshot.

## 🐛 Bug Fixes

- Fixed the GUI styling that the new Content-Security-Policy was blocking by relaxing the production build's critical-CSS inlining and refreshing the asset scope.
- Fixed `git blame` and file history on renamed paths.

## 🔧 Maintenance

- Added specs for the permission overlay, window settings, zoom, hotkeys, agent graph and Git service.
- Bundled the `pdfjs-dist` worker with the app build.
- Pinned all GitHub Actions in the installer workflow to full commit SHAs.
- Added development icon tooling and a `docs/features` illustration set.

## 🔒 Security

- Enforced a strict Content-Security-Policy in production, replacing the previous `csp: null`.
- Removed the wildcard `assetProtocol` scope (`["**"]`) so the frontend can no longer read arbitrary local files.
- Added SSRF protection to `web_fetch`: loopback, private, link-local, unique-local, unspecified and multicast addresses are rejected on every hop, with redirects followed manually so a redirect or DNS rebind cannot reach internal hosts.
- Made the permission broker backend-owned: a renderer decision is validated against the stored pending prompt before any allow rule or folder is persisted.
- Added tests covering nested command programs, shell control operators, quoted operators, saved rules bypassing operators or sensitive paths and fail-closed handling of unparseable commands.
- Denied the internal devtools toggle from the webview and added an explicit webview zoom permission.

## ⚠️ Notes

- Requires Node 24 or newer to build from source.
