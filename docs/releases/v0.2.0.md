# pumr v0.2.0

A look-and-feel release: background presets, sound notifications, per-session
attention indicators and per-project appearance.

## 🚀 Features

- Added around a dozen built-in background presets (aurora, mesh, grid, dots, topo, circuit, hex and more), rendered from inline SVG with no bundled assets.
- Added custom background support, including your own image with adjustable opacity and blur.
- Added notification sounds for finished runs, permission requests and errors, synthesised at runtime with the Web Audio API and dispatched through the OS.
- Added custom sound files to replace any built-in notification sound.
- Added a spinning puma indicator to sessions that are actively working.
- Added pulsing attention dots so sessions waiting on a permission or a question stand out.
- Added per-project appearance settings: colour, icon, letter or an uploaded image.
- Added a glass-effect opacity setting.

## ✨ Improvements

- Rewrote the sidebar, which now groups history into Today, Yesterday, weekday and date sections.
- Sub-agent sessions can be expanded and collapsed inline.
- Sessions are now scoped per project, so permission and question prompts follow the active session.
- Added tracking for focused panels and agent activity in the workspace service.
- Tuned the theme service so custom theme values apply cleanly to background layers.

## 🐛 Bug Fixes

- Fixed session attention handling so prompts no longer linger on the wrong session.
- Fixed smaller sidebar and appearance issues.

## 🔧 Maintenance

- Extracted the pixel-art puma frames into a shared art module.
- Enabled the Tauri asset protocol so user background and icon images can be displayed.

## 🔒 Security

- None.
