# pumr v0.8.2

A release for the composer and the sidebar. `Ctrl+Space` completes the word at the
cursor with the project's files, folders and the classes and functions its code
defines, and `@` followed by the start of a name lists the matching files straight
away. The sessions list shows the branch each project has checked out. The mode
hotkey goes through every mode, and Planning can look things up with commands that
only read. On Linux the text on the glass panels no longer glows with older
WebKitGTK versions.

## 🚀 Features

- Added completion to the composer: `Ctrl+Space` (also on macOS, configurable) completes the word at the cursor with the project's files, folders and the names its code defines, such as classes, interfaces, structs, enums, traits, types, functions, methods, constants and modules. A row shows where the name is defined and what it is. Typing on narrows the list, ending the word or pressing `Escape` closes it and leaves the word as typed, and `Tab`, `Enter` or the right arrow writes the highlighted row in place of the word. The names are read from TypeScript and JavaScript (also in Vue and Svelte files), Rust, Python, Go, Java, Kotlin, Scala, C#, Swift, Dart, PHP, Groovy, C, C++, Objective-C and Ruby; git-ignored files are skipped.
- Added files to the `@` menu right after the `@`: `@compo` lists `composer.ts` and `composer-editor.service.ts` without going through `@file:` first. The letters only have to appear in order, so `@ces` finds `composer-editor.service.ts`; a name that starts with them or holds them in one piece comes first, and a file comes before a folder that matches as well. `Tab`, `Enter` or the right arrow takes the highlighted row.
- Added the checked-out branch to the sidebar: each project in the sessions list shows its branch under its name, and each session in the history shows the branch of its project. A detached HEAD shows its commit. The branches are read again when pumr comes back to the front, so a branch switched in a terminal shows up.

## ✨ Improvements

- The mode hotkey (`⌘⇧P`, `Ctrl+Shift+P` on Linux and Windows) goes through all modes in the order of the mode picker and starts again after the last one, instead of switching between Planning and the mode before it.
- Planning can run commands that only read, such as `git log`, `git diff`, `cat` or `grep`, to look things up while it plans. A command whose line does not show that it only reads is not run there, whatever rule or earlier answer would let it run in another mode, and the agent is told to use a read-only command instead.
- Branch names have a drawn branch icon in place of the `⎇` character, which few fonts draw and none legibly at text size, and the branch next to the project name stands out more.
- A faint grain lies over the window, which hides the bands that the dark theme's gradients and the glass sheen showed in steps of one colour level.

## 🐛 Bug Fixes

- Fixed the text on the glass panels glowing on Linux with WebKitGTK before 2.54 (Ubuntu 24.04, Pop!_OS with COSMIC and the AppImage). That compositor blurs what lies in front of a blur into it as well, so every letter came back blurred around itself. pumr detects it and leaves the panels' blur out there; they keep their tint.

## 🔧 Maintenance

- Added `symbols.rs`, which reads the definitions of a project off the start of their lines with a pattern per language family, and the `list_workspace_symbols` command. It reads at most 4,000 source files, skips files over 512 KB and lines over 400 bytes (minified code) and keeps at most 20,000 names.
- Added the `has_leaky_backdrop` command, which tells the WebKitGTK compositor that leaks the foreground into a backdrop (TextureMapper, before 2.54 or with `WEBKIT_USE_SKIA_FOR_COMPOSITION=0`) from the Skia one.
- Added Rust tests for the symbol patterns, the compositor detection and the commands Planning runs.
- A new e2e spec covers completion and the `@` menu; the git, rendering and slash command specs grew with the branch in the sidebar, the panels without blur and the mode hotkey. The fake backend handles the new commands.
- New unit specs cover the completion ranking and the grain; the composer and mode specs grew with the features above.

## ⚠️ Notes

- The mode hotkey no longer takes a session back to the mode it left for Planning. Pressing it on goes through the other modes and comes back round.
- On macOS `Ctrl+Space` also switches the input source when more than one is set up. Settings → Hotkeys changes the completion hotkey.
- A completed name or path is written into the prompt as plain text. A file added through `@` is still sent along as a reference.
