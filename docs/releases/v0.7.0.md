# pumr v0.7.0

A release for long sessions and an agent that checks its own work. Conversations
are compacted into a stored summary instead of being cut to the newest messages,
the agent keeps a task list, waits for long builds, shows screenshots in the chat
and is asked to run the project's checks before it finishes. A chat that was cut
off by a closed app or a sleeping machine can be continued.

## 🚀 Features

- Added conversation compaction. Once the context is 70% full, or at 150,000 input tokens at the latest, older messages are replaced for the model by a summary; both limits are settings. The chat marks where it happened and keeps every message visible, the summary carries the task list and your latest request word for word, and reverting to an earlier message takes the checkpoint back.
- Added a "Compact context" button in the composer to compact a conversation on request, without leaving the chat.
- Added a `todo` tool: the agent keeps a task list for work with three or more steps. It is shown in the chat and handed back to the agent after a compaction, so progress survives a long session.
- Added a `bash_output` tool: the agent waits for a command that was moved to the background and reads what it printed since it last looked, with how it ended, instead of guessing at the result or running a build twice. `bash` itself may now wait up to 600 seconds (before: 120).
- Added a `screenshot` tool: the agent renders a page of the running app in a headless browser, or shows an image or HTML file, and the picture appears in the chat. The model does not get the picture; it gets what the page logged to the browser console, errors included. Pages on other hosts go through the website rules like a fetch.
- Added "Check changes before finishing" (on by default): an agent that wants to finish after changing code without having run anything is asked once to run one of the project's checks. It costs at most one extra step per turn.
- Added `explore` and `verify` subagents. An explore subagent only searches and reads and reports `path:line` references, which keeps the main agent's context free. A verify subagent gets the list of changed files, runs the project's checks without editing and reports PASS or FAIL per check.
- Added a model per subagent: name it in the prompt ("use deepseek flash for this") and pumr matches the name against the connected providers, the chat's own first. When a name fits several models, a prompt asks which one you meant, once per chat. A subagent that runs on another model than the chat names it.
- Added continuing interrupted chats: a turn that was cut off because pumr was closed, or because the computer went to sleep while a reply was on its way, is marked as interrupted and offers Continue.
- Added a waiting chats banner: when another chat needs a permission or asks a question, a banner at the top of the chat names it, with Switch and Dismiss. It can be turned off in the notification settings.
- Added sorting for projects in the sidebar: alphabetical (the default), last activity or session count. The choice is remembered.
- Added hotkeys for terminal tabs while the terminal is focused: new tab (`Cmd`+`T`, elsewhere `Ctrl`+`Shift`+`T`) and close tab (`Cmd`+`W`, elsewhere `Ctrl`+`Shift`+`W`). Both can be remapped.
- Added live command output: a command that keeps printing has its output opened in the chat and followed as it arrives, including what a `| tail` at the end of a build or test run would hold back until the end.
- Added the cache rate: every request shows the share of its input that came from the provider's prompt cache, and the context meter shows it for the last request.
- Added a debug log export: save a chat as Markdown with your OS, app and WebView versions, every step with its errors and the permission log, to hand to an AI agent. A model you pick can anonymize it first, with a preview of every changed line.

## ✨ Improvements

- The agent is told where it runs: platform, date, Git branch, the project's package manager and its check commands, read from the manifests at the project root. A short working method closes the system prompt; models below $1 per million input tokens, local ones included, get a longer one.
- Old tool output is replaced by a short stub before anything is summarised, and the history otherwise only grows at its end, so providers can serve everything before it from their prompt cache.
- Prompt caching reaches further: OpenRouter requests name their conversation so it stays on the endpoint that holds its cache, Claude models on OpenRouter cache the conversation up to its newest message, and OpenAI requests carry a `prompt_cache_key`.
- A request a provider refuses as longer than the model's context window is compacted and sent once more.
- `grep` can show the lines around each match, list only the matching files with their match counts, ignore case and take a limit.
- `edit` answers with the numbered lines around the change, so the file need not be read again. An `old_string` that matches nowhere is answered with the closest text in the file, and text copied with the line numbers of `read` still matches.
- `write` no longer replaces an existing file the agent has not read in this chat.
- Tool arguments under the names other agents use (`file_path`, `directory`, `timeout` in milliseconds) and of a near-miss type (`"10"` for a number) are understood. Arguments that are no JSON object are reported as such instead of as a missing argument.
- A command output that is too long for a tool result is saved whole to the chat's scratch folder; the result keeps its beginning and end with the path.
- The agent is told when it made the same call with the same result three times, and when three calls of one tool failed in a row.
- The list of changed files follows a running turn and the edits of its subagents instead of waiting for them to end. The file tree, the open file, the open diff and the Git views are read again when a turn changes files.
- The window-toggle shortcut puts the caret in the composer when it brings pumr back, so you can type straight away. An open dialog keeps its focus.
- The review mode's default prompt asks the agent to confirm every finding before it reports it.
- The thinking box shows a collapse chevron, and a model menu docked at the bottom of a panel opens upwards and fits the room it has.

## 🐛 Bug Fixes

- Fixed commands of the agent, MCP servers and `git` not finding tools installed with Homebrew, nvm, cargo and the like when pumr was started from the macOS Finder or a Linux desktop launcher. pumr now takes over the `PATH` of your login shell at start.
- Fixed a reply that was on its way when the computer went to sleep leaving the turn waiting on a connection that was gone. The turn now ends as interrupted and can be continued.
- Fixed typing in the composer redrawing most of the window on Linux without GPU compositing: the panels have a height of their own and the composer follows its text through CSS instead of being sized from script.
- Fixed text typed after a new line at the end of the composer landing on the previous line.
- Fixed menus and popovers outside macOS letting the text underneath show through sharply where the background blur is not painted.
- Fixed the editor replacing what you typed while a file was still being read with the content on disk.
- Fixed keys not reaching the page after the window-toggle shortcut brought back a hidden window.

## 🔧 Maintenance

- The macOS Intel installer is cross-compiled on Apple Silicon runners, tag builds restore the Rust cache of the default branch, and build scripts and proc macros are compiled optimised in release builds, which shortens embedding the frontend.
- The e2e fake backend keeps a project folder with files and a change list, streams tool output, holds a running call, compacts a history, cuts a turn off and raises model choices. New specs cover the changed files, the terminal tabs, compaction, interrupted chats, the waiting chats banner, project sorting and screenshots.
- Added Rust tests for compaction and the stored history, the turn watch, model matching, the login shell `PATH`, sleep detection, background command output and the screenshot tool.
- Added `base64` as a dependency for the pictures of the `screenshot` tool.

## ⚠️ Notes

- The setting "Context messages sent to the model" is gone. Conversations are no longer cut to the newest 40 messages; the two compaction settings under Agent Configuration take its place.
- The `screenshot` tool needs a Chromium-based browser on the machine: Playwright's Chromium, Google Chrome, Chromium or Microsoft Edge. `PUMR_BROWSER` names one outright.
